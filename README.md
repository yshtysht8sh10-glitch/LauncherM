# LauncherM

いつもの作業環境を、ワンクリックで。

LauncherM は、Windows 上でアプリケーション、ファイル、フォルダ、URL などを作業単位で起動することを目指す個人開発のランチャーです。現在は約4年前のWPF試作を調査し、再始動する段階です。

## Current state

既存試作には、登録項目の表示、個別起動、フォルダを開く処理、設定保存、表示設定画面などが含まれています。Workspaceの一括起動などは、まだ実装済みとは扱いません。

## Development

- Windows
- C# / WPF
- .NET Framework 4.8
- Visual Studio 2022

設計思想は [docs/design-philosophy.md](docs/design-philosophy.md)、AI開発向けの現在地は [docs/ai/current-status.md](docs/ai/current-status.md) を参照してください。
