# Development Rules

- Respect `docs/design-philosophy.md`.
- Do not add unrequested features or implement Future Ideas early.
- Do not rewrite the project or refresh the UI without an explicit request.
- Do not change the UI framework without an explicit request.
- Avoid speculative abstraction and overengineering.
- Keep MUGEN-specific behavior separate from Launcher Core.
- Check the impact of behavior changes before editing shared code.
- Do not infer completion from code presence alone.
- Distinguish Planned, Implemented, and Verified.
- Run Build, focused checks, and real execution where practical.
- Record anything that could not be verified.
- Update relevant AI documentation when implementation changes.
- Keep work focused when unrelated issues are discovered.
